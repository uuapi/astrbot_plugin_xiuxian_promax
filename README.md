## 🚀 快速上手

> 安装插件并重启 AstrBot 后，发送以下指令开始修仙之旅：

```
/我要修仙              # 创建角色（选职业：灵/体/魔/剑/鬼/佛/御兽）
/闭关                  # 挂机修炼 → /出关 领取修为
/签到                  # 每日签到（节日大奖）
/突破                  # 修为够了就突破境界
/开始历练 巡山问道      # 挂机历练赚灵石
/除妖                  # 野外战斗刷怪（每日5次）
/镇妖塔                # 爬塔挑战（每日3次）
/宗门捐献 1000         # 加入宗门后为宗门出力
```

<details>
<summary><b>🔀 数据流架构</b></summary>

```
玩家消息 → AstrBot Pipeline → @filter.command 路由
    → main.py handler → handler 方法 → manager 方法
        → data_manager / database_extended
            → SQLite (WAL, 原子操作)

并发保护：
    CAS (syscfg_cas)          → 状态抢占
    syscfg_claim_slot         → 限次认领
    syscfg_adjust_number      → 原子累加
    syscfg_spend              → 条件扣减
    add_player_gold/exp       → 原子记账
    条件原子扣款               → WHERE gold >= ?
    claim_user_free_if_type   → 结算门禁
    begin_immediate           → 事务串行化
```

</details>

## ⚙️ 配置

插件首次启动自动生成配置文件，可在 AstrBot WebUI 中修改：

| 配置项 | 说明 | 默认值 |
|:---|:---|:---|
| `BOSS_ADMINS` | 管理员 QQ 号列表 | `[]` |
| `WHITELIST_GROUPS` | 白名单群号列表 | `[]` |
| `IMAGE_CARDS` | 卡片渲染开关 | 启用 |

<details>
<summary><b>游戏数值配置（config/ 目录 17 个 JSON）</b></summary>

| 文件 | 内容 |
|:---|:---|
| `level_config.json` | 65 层境界（修为需求/突破成功率/属性增益） |
| `pills.json` | 26 种突破丹 |
| `exp_pills.json` | 30 种修为丹 |
| `utility_pills.json` | 120+ 功能丹 |
| `weapons.json` | 武器（五行/品阶/词条） |
| `items.json` | 材料/装备 |
| `sect_config.json` | 宗门配置 |
| `boss_config.json` | Boss 配置 |
| `rift_config.json` | 秘境配置 |
| `alchemy_config.json` | 炼丹配置 |
| `adventure_config.json` | 历练路线 |
| `bounty_templates.json` | 悬赏模板 |
| `storage_rings.json` | 储物戒 |
| `techniques.json` | 功法 |
| `game_config.json` | 全局游戏参数 |

修改后重启 AstrBot 生效。

</details>

## 🤝 贡献

欢迎提交 PR！开发前请阅读 [AGENTS.md](AGENTS.md) 了解项目规范。

```bash
# 开发环境搭建
git clone https://github.com/<你的用户名>/astrbot_plugin_xiuxian_promax.git
cd astrbot_plugin_xiuxian_promax
pip install ruff pyflakes

# 提交前必须通过
python -m unittest discover -s tests     # 107 项测试
python scripts/check_syntax.py           # 语法检查
ruff check . --select F821,F823,F401,F841,B007,E722  # Lint
python scripts/_final_check.py           # 指令覆盖
```
