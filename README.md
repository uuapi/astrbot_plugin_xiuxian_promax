## 🚀 快速上手

```bash
# 1. 安装插件到 AstrBot
cd AstrBot/data/plugins
git clone https://github.com/uuapi/astrbot_plugin_xiuxian_promax.git

# 2. 重启 AstrBot（自动建表 v29 + 生成配置文件）

# 3. 开始修仙
/我要修仙    # 创建角色
/闭关        # 挂机修炼
/出关        # 领取修为
/突破        # 境界提升
```

<details>
<summary><b>🔀 并发保护设计</b></summary>

本项目使用 SQLite WAL 模式 + 单共享连接 + 原子原语防并发：

```
┌──────────────────────────────────────────────────────────┐
│                    并发保护体系                             │
├──────────────────────────────────────────────────────────┤
│ syscfg_cas(key, new, old)      → CAS 比较交换              │
│ syscfg_claim_slot(key, n)      → 原子限次认领              │
│ syscfg_adjust_number(key, Δ)   → 原子数值增减             │
│ syscfg_spend(key, amount)      → 条件原子扣减              │
│ add_player_gold(uid, ±n)       → 原子金币（钳 0）          │
│ 条件扣款 WHERE gold >= ?       → 防透支                    │
│ claim_user_free_if_type()      → 状态门禁                   │
│ begin_immediate()              → 事务串行化（冲突让步）     │
├──────────────────────────────────────────────────────────┤
│ 设计原则：                                                  │
│   检查 → CAS 抢占 → 条件扣款 → 发奖                        │
│   任一步失败 → 原子退款回滚，不产生半状态                    │
└──────────────────────────────────────────────────────────┘
```
